# Research Agent Eval

面向科研工作流的 LLM/Agent 评测方法探索, 关注任务设计, 证据核验和失败案例分析.

[English](README.md) · [当前进度](docs/progress.md) · [评价方法](docs/methodology.md)

项目从计算数学研究中的实际问题出发: 回答是否定位到真实来源, 是否检查了结论所需的假设, 是否区分证明, 有限数值观察和待验证判断. 目标是将这些要求组织成可核查的任务与评价依据.

**当前为早期探索的公开进度快照.** 本仓库整理了已有个人原型中的部分组件, 并增加了使用原创合成材料的演示. 完整科研题库尚未在这里发布, 当前内容也不提供模型排名.

## 运行

需要 Node.js 22 或以上版本. 示例没有第三方依赖, 无需模型调用或 API key.

```sh
git clone https://github.com/Xingwei0724/research-agent-eval.git
cd research-agent-eval
npm run validate
npm test
npm run demo
```

`validate` 检查公开任务的主要结构字段与输入文件哈希. `test` 检查评分规则与已知失败样例. `demo` 展示局部评分结果, 并生成一次脚本指定操作的工具轨迹 `output/demo-trace.json`. 该轨迹展示记录机制, 不用于评价模型自主选择工具的能力.

## 当前研究重点

- 从文献证据定位, 定理假设核查, 结论迁移和论文/代码/实验一致性等工作中设计任务.
- 分别考虑固定输入下的模型输出, 以及包含工具与上下文配置的完整工作流表现.
- 区分数学正确性, 证据可靠性, 假设与结论边界, 研究判断和任务完成情况.
- 用正确, 错误与近失误样例检查评分规则, 将需要研究判断的部分交给人工复核.

原型的任务登记有 7 项, 处于 exploratory/pilot 阶段. 这些任务的历史状态与本仓库实际可复现的内容分别写在[进度说明](docs/progress.md)中. 后续需要扩充可公开材料, 对照人工判断校准评分规则, 并在冻结条件下进行重复运行.

## 本地维护与发布

在完整研究工作区中, 本仓库位于 `benchmark/research-agent-eval/`. 父目录 `benchmark/` 保存原始科研任务, 来源材料, 试点记录和设计决策; `research-agent-eval/` 是独立的 Git 仓库, 用于公开版代码, 文档和演示的整理与发布.

研究目录的修改不会自动同步到公开版. 将经过核对的内容选入本仓库后, 在本仓库根目录检查差异, 提交并推送. 单独克隆本仓库即可运行全部公开示例, 无需父目录中的研究材料.
